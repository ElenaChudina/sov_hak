# H2 – Nyt hakkeroidaan ja koodataan

## x) Teoria

Tutustuin OWASP Top 10 -listan kohtaan A01 Broken Access Control. Siinä käyttäjä voi päästä käsiksi sivuihin tai toimintoihin, joihin hänellä ei pitäisi olla oikeuksia.

Tutustuin myös ffuf-työkaluun. Sillä voidaan etsiä web-sovelluksesta piilotettuja URL-osoitteita sanalistan avulla.

PortSwiggerin materiaalissa käsiteltiin access control -haavoittuvuuksia. Käyttöoikeudet pitää tarkistaa palvelimella eikä vain selaimessa.

## a) 010-staff-only

Aloitin lataamalla Teron tarvittavat ohjelmat, jotta pääsen suorittamaan tehtävät.

`wget https://terokarvinen.com/hack-n-fix/teros-challenges.zip`

`unzip teros-challenges.zip`

`sudo apt install wget unzip python3-flask python3-flask-sqlalchemy`

## b) 010-staff-only – korjaus

Etsin haavoittuvan kohdan `staff-only.py`-tiedostosta.

Alkuperäinen koodi oli:

`sql = "SELECT password FROM pins WHERE pin='"+pin+"';"`

<img width="937" height="447" alt="Näyttökuva 2026-09-23 121509" src="https://github.com/user-attachments/assets/4af5ce7b-3d7a-4533-a0ea-48bd32f1392e" />


Käyttäjän syöte meni suoraan SQL-kyselyyn.

Korjasin sen parametrisoiduksi kyselyksi:

`sql = "SELECT password FROM pins WHERE pin=:pin;"`

ja:

`res=db.session.execute(text(sql), {"pin": pin})`

Tarkistin myös Python-tiedoston syntaksin komennolla:

`python3 -m py_compile staff-only.py`

Sen jälkeen testasin samaa SQL injection -syötettä uudelleen. Se ei enää toiminut ja sovellus näytti:
`Your password is (not found)`

## d) 020-your-eyes-only

Käynnistin `020-your-eyes-only`-sovelluksen ja avasin sen selaimessa:

`http://127.0.0.2:8000`

Aluksi portti 8000 oli jo käytössä. Avasin uuden terminaalin ja tarkistin, mikä prosessi käytti porttia komennolla:

`ss -ltnp | grep ':8000'`

Tuloksessa näkyi, että `dirfuzt-1` käytti porttia 8000. Lopetin prosessin eli `kill 3649` ja käynnistin Django-sovelluksen uudelleen.

Sen jälkeen sovellus avautui normaalisti selaimessa.

Sovelluksessa oli Admin dashboard -linkki, mutta se johti login-sivulle. Kokeilin myös avata admin-sivun suoraan:

`http://127.0.0.2:8000/admin-console`

Sivu avautui ilman admin-oikeuksia ja siellä näkyi:

`Well done, you've found the secret page.`
