# Lab3 – Crackme-ohjelman salasanan etsiminen

Valitsin tehtävästä ohjelman `crackme01.64`.

Ensin kokeilin ajaa ohjelmaa:

```bash
./crackme01.64
````
Ohjelma ilmoitti:

Need exactly one argument

Tästä ymmärsin, että ohjelma tarvitsee yhden argumentin.
<img width="626" height="88" alt="Näyttökuva 2026-09-01 210838" src="https://github.com/user-attachments/assets/0510919c-f936-4cc0-8eb0-697c0ae26d2d" />

Käynnistin ohjelman GDB:llä: gdb ./crackme01.64

GDB ilmoitti, ettei ohjelmasta löytynyt debugging symboleja

Asetin breakpointin main-funktioon: break main

Sen jälkeen käynnistin ohjelman testiarvolla: run test

Ohjelma pysähtyi main-funktioon.
<img width="755" height="185" alt="Näyttökuva 2026-09-01 211139" src="https://github.com/user-attachments/assets/ce020fb2-7f37-401c-9e5f-9ed62c61ffce" />

Koska lähdekoodia ei ollut käytettävissä samalla tavalla kuin aikaisemmissa tehtävissä, katsoin ohjelman assembler-koodia komennolla: disassemble main

Koodissa näkyi strncmp-funktio. Se tarkoittaa, että ohjelma vertaa kahta merkkijonoa keskenään.

Asetin breakpointin kohtaan, jossa strncmp kutsutaan: break *main+30

Käynnistin ohjelman uudestaan testiarvolla: run password!

Kun ohjelma pysähtyi breakpointiin, tarkistin rekisterien sisällöt: x/s $rdi

Tulos oli: "password!"

Tämä oli siis itse antamani salasana.

Sen jälkeen tarkistin toisen merkkijonon: x/s $rsi

Tulos oli: "password1"

Tämä oli oikea salasana, jota ohjelma vertasi antamaani arvoon.

Tarkistin myös vertailun pituuden: print $rdx

Tulos oli: $2 = 9

## Mitä opin

Opin käyttämään GDB:tä ja `disassemble`-komentoa. Opin myös, että GDB:llä voi katsoa rekisterien sisältöä.

Ensin luulin, että `password!` oli oikea salasana, mutta se ei toiminut. Sitten löysin GDB:n avulla oikean salasanan `password1`.

## Mitä en vielä osaa

Assembler-koodi on vielä minulle vaikeaa. En ymmärrä kaikkia GDB:n komentoja, joten tarvitsen vielä lisää harjoittelua.
